**Internal Price Processor** - микросервис для получения финансовых данных криптовалют и фиата.

Представляет собой микросервис, который соединяется с различными информационными ресурсами (биржи, обменники) для получения данных о курсах, рынке и т.д.


# Описание таблиц БД
`bases`, `quotes`, `exchange` - таблицы, хранящие константы, которые будут служить как важные значения для других таблиц. Все пишутся в заглавном регистре.


`history_prices` - таблица, хранящая историческую информацию о тикерах: базовые, котировочные валюты, цена, биржа и время.


`metric_prices` - таблица, хранящая метричную информацию о каждом тикере в единственном экземпляре: BTC, ETH, SOL, TRX, TON к USDT. Не хранит биржу.


`history_market_stats` - таблица, хранящая информацию о рынке определенной валюты.
